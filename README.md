# Tabuada JS

Gerador de tabuada interativo feito com HTML, CSS e JavaScript puro.

## Sobre o projeto

O usuário informa um número e até qual multiplicador deseja calcular. Ao confirmar, a tabuada é gerada dinamicamente na página, exibindo cada operação e seu resultado em formato de tabela.

## Funcionalidades

- Escolha o número base da tabuada
- Defina até qual multiplicador calcular (padrão: 10)
- Resultado exibido de forma clara e organizada
- Validação básica dos campos antes de calcular

## Tecnologias

- HTML5
- CSS3 (Flexbox, gradiente de fundo)
- JavaScript (DOM, DOMParser, eventos de formulário)

## Como usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/tabuada.git
   ```
2. Abra o arquivo `index.html` no navegador.

Não há dependências externas nem necessidade de servidor.
